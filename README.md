# Задачи

Личный органайзер задач по ботам. Страница: `index.html` (GitHub Pages).
Задачи хранятся на нашем сервере (`server/server.mjs`, адрес `https://lk.24kitbot.ru/tasks-api/`),
отчёты уходят в MAX от бота доски: Маше в личку, в администрацию бота (канал) или «Всем» — в оба места.

Проверка сервера: `cd server && node --test server.test.mjs`
